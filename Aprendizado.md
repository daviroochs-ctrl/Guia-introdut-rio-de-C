# Aprendizados

Até agora aprendi sobre variáveis, condições, laços, especificadores, cast e mais alguns detalhes da linguagem C.

## O que já sei fazer

Consigo criar programas que demandam o uso de laços (`while` e `for`), condições (`if` e `else`) e operadores lógicos da linguagem (`&&`, `||` e `!`). Com isso, já consigo escrever programas que verificam se um número é primo, calculam seu antecessor e sucessor, testam se ele satisfaz determinada condição, e identificam se é par ou ímpar.

Foi a partir da prática de criar esses programas — não só da teoria — que consegui de fato absorver o conteúdo. Conhecimento sem aplicação não se firma: só entendi de verdade quando errei, depurei e ajustei o código com as próprias mãos.

## Principais dificuldades até agora

Minha principal dificuldade está nas diferenças entre Python e C. Como Python é uma linguagem com muito mais automação — e era a que eu já estava habituado a usar —, senti dificuldade por precisar escrever explicitamente coisas que em Python aconteciam de forma implícita, como a declaração de tipos e o gerenciamento mais manual da lógica do programa.

## Comparações com o que eu já sabia (Python)

Comparando o que sei em Python com o que sei em C, ainda noto uma discrepância grande. Em Python, sinto que tenho um repertório muito mais amplo de ferramentas prontas para resolver um problema — funções embutidas, tipagem dinâmica, sintaxe mais enxuta. Em C, cada solução exige mais passos explícitos. Acredito, porém, que com o tempo e mais prática, C vai se tornar tão intuitivo quanto Python é hoje para mim.

## Próximos passos no aprendizado

Meu objetivo é trazer, cada vez mais, o conhecimento que já tenho em Python para dentro do universo de C — usando a lógica que já domino como base para entender mais rápido os novos conceitos, ao mesmo tempo em que assimilo o que é exclusivo do funcionamento de C (como tipagem estática e gerenciamento de memória).

## Reflexão sobre usar Git/GitHub durante o processo

Usar Git e GitHub durante esse processo tem me ajudado muito a organizar o aprendizado. Registrar cada etapa em commits me obriga a estruturar o que estou estudando de forma mais clara, e ter esse guia versionado cria um histórico visível da minha evolução — algo que fica mais difícil de enxergar quando o aprendizado fica só espalhado em anotações soltas.
