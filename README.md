# Guia introdutório de C

## Objetivo
Ajudar estudantes que estão iniciando sua jornada de aprendizagem da linguagem C.


## Público-alvo
Estudantes que já têm alguma noção básica de lógica de programação e 
querem aprender C como próxima linguagem, entendendo conceitos de mais 
baixo nível como tipagem estática e compilação.

## Pré-requisitos
Nenhum conhecimento prévio de C é necessário. Recomenda-se ter familiaridade 
básica com lógica de programação (variáveis, condicionais, laços) em 
qualquer linguagem.

Conceitos fundamentais, pratique com os Exercícios e consulte as 
Referências sempre que precisar de material de apoio.
